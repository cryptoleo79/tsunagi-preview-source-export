Independent Development

独立した開発

実際のインフラ開発。透明な進捗。制度的依存なし。

TSUNAGIは独立した実装プロジェクトです — Zigでゼロから書かれた決定論的Cardanoノードアーキテクチャ。可観測性、ランタイムの明瞭性、オペレータ第一の設計原則に基づくノードインフラの構築を目指す、個人のエンジニアリング活動として始まりました。

決定論的台帳パイプライン、シャドウ検証システム、LMDB永続化層、4つの可観測性サブシステム（KAGAMI・YAMORI・TATE・KURA）、継続的なプレビューネットワーク検証 — これらすべてが、制度的助成金、ガバナンス資金、ベンチャーキャピタルなしに、日々のエンジニアリングを通じて構築されてきました。

トレジャリーモデルと支援パスは公開されています。TSUNAステークプールを通じた支援が、継続的な開発とインフラコストを支えています。

System Design

アーキテクチャ

TSUNAGIは、各サブシステムが特定の運用課題に対応する層構造として設計されています。可観測性スタック（KAGAMI・YAMORI・TATE・KURA）がノードの監視と安定化を担い、TSURUGIプロトコルエンジンがOuroboros通信を管理します。決定論的台帳パイプラインがモジュラー状態機械を通じてブロックを処理し、LMDBがトランザクション保証付きの永続ストレージを提供します。

Foundation

基本設計原則

TSUNAGIアーキテクチャを支える4つの基盤。

Ledger Engine

決定論的台帳

デルタ抽出、状態適用、アンドゥ管理、永続ストレージを独立してテスト可能なコンポーネントに分離するモジュラーパイプライン。グローバル状態なし。同一入力からは常に同一出力が生成されます。

Verification

シャドウ検証

独立したパイプラインインスタンスが、各ブロックで同一デルタを処理し、プライマリ台帳とのパリティを比較します。乖離は1ブロック以内に検出されます。シャドウがプライマリパスに影響を与えることはありません。

Persistence

LMDB真実モード

プリフライトカバレッジスキャン、アトミックLMDB書き込み、自動メモリフォールバックの3段階永続化。シャドウ書き込みがストアとライブチェーン状態を段階的に収束させます。オペレータが必要な永続化保証レベルを選択可能です。

Operations

自律修復インフラ

4つの可観測性サブシステム — KAGAMI・YAMORI・TATE・KURA — が健全性を評価し、整合性を検証し、アーティファクトを自動的に安定化します。ノード自身が、外部からの推測を必要とせず、自らの健全性を説明します。

TSUNAGI Full Site Deployment
=============================

This document explains how to deploy the complete tsunagi.tech
website to a VPS running nginx.

Web root: /var/www/tsunagi

sudo mkdir -p /var/www/tsunagi

=== STEP 8: Copy whitepaper source files ===

# Markdown source (fetched by the HTML whitepaper page):
sudo cp docs/whitepaper/tsunagi-whitepaper.md /var/www/tsunagi/docs/whitepaper/tsunagi-whitepaper.md

# PDF (linked from Download PDF button):
sudo cp docs/whitepaper/tsunagi-whitepaper-v1.pdf /var/www/tsunagi/docs/whitepaper/tsunagi-whitepaper-v1.pdf

=== STEP 9: Copy architecture article ===

sudo cp docs/articles/building-tsunagi.md /var/www/tsunagi/docs/articles/building-tsunagi.md

=== STEP 10: Set permissions ===

sudo chown -R www-data:www-data /var/www/tsunagi
sudo chmod -R 755 /var/www/tsunagi

=== STEP 11: Reload nginx ===

sudo nginx -t && sudo systemctl reload nginx

=== NGINX CONFIGURATION NOTES ===

Ensure nginx is configured to:
- Serve index.html for directory requests (try_files $uri $uri/ =404)
- Serve correct MIME types for .md files (text/markdown or text/plain)
- Serve correct MIME types for .pdf files (application/pdf)
- Enable gzip for HTML, CSS, JS, and text files

Example location block:

  location / {
      root /var/www/tsunagi;
      index index.html;
      try_files $uri $uri/ $uri/index.html =404;
  }

  location ~* \.(md)$ {
      root /var/www/tsunagi;
      default_type text/plain;
  }

=== NOTES ===

- All HTML pages are fully self-contained with inline CSS.
- The whitepaper page uses JavaScript to fetch and render markdown.
- The status, explorer, and decode pages use JavaScript to fetch
  /status.json for live telemetry data.
- All other pages (manifesto, roadmap, treasury, install, vision,
  network) are pure static HTML/CSS.
- No external CDN dependencies or frameworks are used on any page.
- The logo file name may vary. Check web/index.html for the exact
  src path referenced in the hero section.

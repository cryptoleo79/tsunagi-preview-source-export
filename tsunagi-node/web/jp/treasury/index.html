TSUNA Pool — 稼働中

1. トレジャリーが必要な理由

独立したインフラ開発には持続可能な資金が必要です。TSUNAGIは制度的な資金構造の外で開発されています — Catalystへの提案なし、ガバナンス助成金なし、ベンチャーキャピタルなし。このプロジェクトは、デリゲーターおよび支援者からの透明で自発的な支援に依存しています。

持続的な開発には以下のリソースが必要です：

  • インフラ — プレビューおよびメインネットの検証ノードに必要なサーバー、ネットワーク帯域、ストレージ。
  • テスト — 長時間ソーク実行、クロスネットワーク検証、スナップショット整合性検証には、専用の計算資源が必要です。
  • 研究 — プロトコル仕様の分析、クロスチェーン実験、代替ストレージエンジンの評価。
  • エンジニアリング時間 — 決定論的パイプライン、シャドウ検証、可観測性スタック、永続ストレージは、数千時間の集中したエンジニアリングの成果です。
  • 長期メンテナンス — プロトコルアップグレード、ハードフォーク互換性、セキュリティパッチ、運用ツールは、ネットワークの存続期間を通じた継続的な注力が必要です。

2. 独立したエンジニアリング

TSUNAGIは、独立した研究開発活動として始まりました。このプロジェクトは、制度的な助成金、ガバナンス資金、ベンチャーキャピタルなしに構築されてきました — 個人の取り組みと、Cardanoが実装の多様性、決定論的インフラ、オペレータ第一の設計から恩恵を受けるという確信のみによって維持されています。

この独立性は意図的なものです。開発の優先順位は、提案サイクルや資金委員会、外部のロードマップ要件ではなく、エンジニアリングの判断と運用上の現実に基づいて決定されます。アーキテクチャは、何が資金調達可能かではなく、技術的メリット — 決定論的実行、明示的メモリ管理、組み込みの可観測性 — のために行われた選択を反映しています。

これまでの成果 — 決定論的台帳パイプライン、シャドウ検証、LMDB永続化、4つの可観測性サブシステム、継続的なプレビューネットワーク検証 — は、数千時間の集中したエンジニアリングを表しています。この水準の取り組みを維持するには、独立性に見合った資金モデルが必要です：透明で、コミュニティに整合し、制度的依存から自由なモデルです。

コミュニティの支援が重要なのは、独立したインフラ開発が独立を維持するためには、持続可能になる必要があるからです。以下に説明するトレジャリーモデルは、プロジェクトを定義するエンジニアリングの自律性を守りながら、持続可能性を実現するよう設計されています。

3. TSUNAGIの資金モデル

TSUNAGIトレジャリーは、TSUNAステークプール — Cardanoのステーキングモデルに整合したオンチェーン資金メカニズム — を通じて運営されています。

  • 貢献はTSUNAGIトレジャリーウォレット — プロジェクト資金に専用のCardanoアドレスで、ADAハンドル$tsunagi経由で到達可能 — に送られます。
  • トレジャリーウォレットはTSUNAステークプール（TSUNAGI Infrastructure）にデリゲートされ、貢献されたADAがネットワークに積極的に参加します。
  • デリゲートされたトレジャリーステークは生産的になります：時間とともに複利でステーキング報酬を獲得し、自己強化型の資金メカニズムを生み出します。
  • ステーキング報酬は継続的なノード開発、インフラコスト、研究活動を支援します。
  • すべてのトレジャリー活動はオンチェーンで公開されています。コミュニティのメンバーは、トレジャリーウォレットの残高、デリゲーション状況、トランザクション履歴を検証できます。

4. 透明性の原則

  • トレジャリーウォレットアドレス — プロジェクト専用アドレス。公開後、オンチェーンで検証可能。
  • ステークプールID — プールティッカーとプールIDが公開され、デリゲーターがデリゲーション状況を検証可能です。
  • 支援アドレス — 貢献用の専用ADAハンドルまたはアドレスで、個人ウォレットとは区別されています。
  • 公開資金説明 — この文書が、トレジャリーモデルとその原則の正式な説明です。
  • 資金の分離 — トレジャリーウォレットは、プロジェクト資金に専用の独立したアドレスです。個人資金との混合はありません。

5. このモデルが重要な理由

  • 自律維持型インフラ資金。 トレジャリーは、定期的な助成金や一回限りの寄付に依存せず、継続的なステーキング報酬を生成します。
  • 助成金への依存度低減。 開発の優先順位は、資金タイムラインやガバナンスサイクルではなく、エンジニアリング要件によって設定されます。
  • Cardanoステーキングモデルとの整合。 トレジャリーステークはデリゲート先のプールを強化し、分散化に貢献します。
  • 長期的なエコシステムの回復力。 持続可能な資金を持つ独立した実装は、永続的なインフラの多様性を提供します。

Experimental Environment

TSUNAGI Labs

Infrastructure Experiments and Protocol Tooling

TSUNAGI Labs provides access to the internal mechanics of the TSUNAGI node. Each tool exposes a different aspect of the runtime — block decoding, ledger telemetry, and operational diagnostics — built from the same deterministic pipeline that powers the node.

Experiments

Active Tooling

Block Decoder
Visual inspection of decoded block structures, transaction deltas, and CBOR-level ledger data.
→ /decode/
Diagnostics
Runtime Telemetry
Live health metrics from the running node. Sync progress, tip age, subsystem status, and resource utilization.
→ /status/
Ledger View
Block Explorer
Timeline view of block processing events. Decode results, ledger deltas, and chain activity in real time.
→ /explorer/
Operations
Operator Tooling

→ /operator/
CBOR Tools
CBOR Playground
Paste CBOR hex and decode it into a readable tree. Pure JS, no dependencies, runs entirely in-browser.
→ /labs/cbor-playground.html
Mempool
Transaction Observatory
Live decoded summaries of mempool transactions. Inputs, outputs, fees, and metadata from the submission path.
→ /labs/mempool.html
Confirmation
Confirmation Tracker
Correlates locally submitted transactions with block inclusion. Tracks confirmation time via exact txid matching.
→ /labs/confirmation.html
Consensus
Slot Observatory
Chain rhythm observation. Tracks block arrivals per slot and computes inter-block gaps to visualize chain density.
→ /labs/slots.html
Network

Peer connection events, block arrival tracking, and network activity timeline from the node's perspective.
→ /labs/network.html

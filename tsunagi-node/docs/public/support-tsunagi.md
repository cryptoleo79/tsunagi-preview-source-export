## About the Project

TSUNAGI is a deterministic Cardano node architecture written entirely in Zig. The system implements the Ouroboros node-to-node protocols, maintains a live UTxO set through a modular ledger pipeline, and provides runtime verification through an independent shadow ledger system.

The project contributes to Cardano's ecosystem resilience by providing an independent implementation derived from the protocol specification, offering implementation diversity and cross-validation capability for the network.

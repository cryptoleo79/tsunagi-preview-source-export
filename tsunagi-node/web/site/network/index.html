How This Will Work

Future TSUNAGI nodes may expose telemetry via /status.json endpoints, providing a standardized interface for reporting chain tip, health status, coverage metrics, and ledger state.

This network page will aggregate data from registered node endpoints, polling each node's /status.json to build a unified view of the TSUNAGI network's operational state.

Each participating node reports its current chain tip, overall health status, block coverage percentage, and ledger state summary. This data enables network-wide health monitoring and anomaly detection across all independent TSUNAGI infrastructure.

Aggregation across multiple nodes will surface patterns that are invisible from any single node's perspective — enabling detection of chain splits, propagation delays, and coverage gaps across the independent node fleet.

No timeline is promised for this evolution. TSUNAGI is infrastructure research, built incrementally as each layer proves itself reliable. The foundation exists; the network view will emerge when there are nodes to aggregate.

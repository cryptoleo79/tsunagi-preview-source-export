# Tsunagi Manifesto

Tsunagi means connection.

Not just network packets.
Not just peers.
Connection between discipline and care.
Between engineering and responsibility.
Between Japan and the world.

Cardano was born in Japan.
Tsunagi continues that lineage — not through imitation,
but through precision.

We build with three principles:

## 1. Resilience

A node must not panic.
It must not corrupt state.
It must not drift silently.

It must detect.
It must recover.
It must endure.

Rollback-safe.
Deterministic replay.
Ledger invariants enforced.

Infrastructure that survives.

## 2. Precision

Zig-native.
Explicit memory control.
No hidden runtime magic.
No undefined behavior tolerated.

Every byte accounted for.
Every delta verifiable.
Every snapshot reproducible.

A node is not a script.
It is a machine.

## 3. Omotenashi

Omotenashi is not hospitality as performance.
It is care without expectation.

Tsunagi is built so that:

Operators can recover from mistakes.
Stake pools can restart safely.
Infrastructure can self-heal.
Future engineers can understand the code.

We build systems that respect the people who depend on them.

## The Long Vision

Tsunagi begins as a follower.

It becomes a state authority.

It becomes a bootstrap node.

It becomes a full Zig-native Cardano node.

Fast.
Deterministic.
Resilient.
Independent.

Not the loudest node.

The one that does not break.

**Tsunagi — A resilient heart of code, forged in Japan, built for the world.**

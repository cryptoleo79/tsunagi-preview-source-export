TSUNAGI Block Decoder — Deployment Notes
==========================================

Page:    /decode/
Source:  web/decode/index.html
Model:   Static HTML with dynamic JSON fetch

=== DEPLOYMENT ===

1. Create directory on server:

   sudo mkdir -p /var/www/tsunagi/decode

2. Copy to server:

   sudo cp web/decode/index.html \
     /var/www/tsunagi/decode/index.html

3. Reload nginx if needed:

   sudo nginx -t && sudo systemctl reload nginx

=== DEPENDENCY ===

This page fetches /status.json on every load and every 10 seconds.
The status JSON must be available at:

  /var/www/tsunagi/status.json

If status.json is missing or unreachable, the page displays a
graceful "Decoder Unavailable" state with dimmed panels.

The status JSON is generated by:

  scripts/generate-status-json.sh

See scripts/README-status-json.txt for automation details.

=== EXPECTED JSON FIELDS ===

The decoder reads all 20 fields from status.json:

  network, slot, block, tip_hash, fwd, back, utxo, tps,
  shadow_enabled, primary_mode, status, updated_at,
  tx_count, utxo_consumed, utxo_produced, utxo_delta,
  coverage_found, coverage_total, fallback_used, tip_age_seconds

Missing or null fields display as em dash.

=== DIFFERENCES FROM OTHER PAGES ===

  /status/    — Health-focused dashboard with all 20 fields
  /explorer/  — Block activity viewer with timeline event
  /decode/    — Decode pipeline visualization with flow diagram
